Cover Snap Studio turns your own photos into GTA-style cover art: pick photos, fill the poster's panels (one photo cropped four ways, or a different photo per panel), drag and zoom each crop, choose a layout and a colour grade — Vice Sunset, Neon Night or Gold Hour — set a bold two-tone caption, and export a PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080. The preview canvas is drawn by the same renderer as the export, so what you see is the file you get. Static files, no build step, fully offline: photos are read on your own machine and never uploaded. Two sample photos ship in `app/samples/`. Original art direction throughout — no Rockstar logos, artwork or fonts.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
